# ADR-002: Service-Based architecture

- Status: Active

In the context of
- seperated chat module with government surface,
- and the embedded vector space.

facing the need for
- maintainability for the large language model

we decided for
- choosing an architecture of SBA.

achieving
- seperated modules accross the platform with easier testability.

accepting that
- individually lower level of elasticity and responsiveness.
